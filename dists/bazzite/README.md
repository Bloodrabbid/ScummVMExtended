# ScummVM для геймпада — The Longest Journey на Bazzite (ROG Ally / Steam Deck)

Это сборка ScummVM с гибридным управлением **геймпад + тачскрин** для движка
Stark (*The Longest Journey* / «Бесконечное путешествие»), собранная как
переносимый **AppImage x86_64** для портативных Linux-консолей под **Bazzite**.

> ⚠️ **Файлы игры не входят в сборку и не распространяются.** Нужны свои легально
> приобретённые данные *The Longest Journey* (диски/GOG/Steam). AppImage — это
> только движок.

## Установка

1. Скачай `ScummVM-TLJ-Gamepad-*-x86_64.AppImage` со страницы
   [**Releases**](https://github.com/Bloodrabbid/ScummVMExtended/releases).
2. В **Desktop Mode** сделай файл исполняемым:
   ```bash
   chmod +x ~/Downloads/ScummVM-TLJ-Gamepad-*-x86_64.AppImage
   ```
   (удобно переложить в `~/Applications/`).
3. Запусти двойным кликом или из терминала. Если не стартует из-за FUSE:
   ```bash
   ./ScummVM-TLJ-Gamepad-*-x86_64.AppImage --appimage-extract-and-run
   ```

## Добавление игры

1. Скопируй файлы *The Longest Journey* на устройство (например,
   `~/Games/TLJ/`).
2. В ScummVM: **Add Game…** → выбери папку с данными игры → сохрани.
3. Проверь, что геймпад определяется (в логе запуска — строка
   `Using game controller: …`).

## Запуск в Gaming Mode

1. В **Desktop Mode**: Steam → **Add a Non-Steam Game** → выбери AppImage.
2. Вернись в **Gaming Mode**, открой добавленный ярлык.
3. В свойствах контроллера выбери шаблон **Gamepad** (или Gamepad with Mouse
   Trackpad). Steam Input прокидывает виртуальный Xbox-контроллер, и движок
   видит его напрямую.
4. Если правый стик (курсор) ведёт себя не так — в раскладке Steam Input задай
   правому стику режим **Joystick Move → As-is** (не Mouse), либо **отключи
   Steam Input** для этого ярлыка, тогда ScummVM читает контроллер сам.

## Подменить оригинал из Steam своим билдом

Steam-версия *The Longest Journey* сама работает на ScummVM, поэтому можно
оставить запись игры (обложку, слот в библиотеке) и заставить её кнопку **Play**
запускать этот билд с твоими данными.

1. Один раз в Desktop Mode добавь свою игру в AppImage (**Add Game…**) и запомни
   **ID цели** в её свойствах, например `tlj-win-ru`. Конфиг хранится в
   `~/.config/scummvm/`, так что добавлять нужно только раз.
2. Steam → **The Longest Journey** → **Properties → Launch Options**:
   ```
   bash -c 'exec "/home/<user>/Applications/ScummVM-TLJ-Gamepad-v0.1-x86_64.AppImage" tlj-win-ru'
   ```
   Замени `<user>`, путь к AppImage и `tlj-win-ru` на свои. `exec` запускает твой
   билд, а дописываемый Steam-ом `%command%` игнорируется.
3. Если в Gaming Mode не стартует из-за FUSE — добавь флаг:
   `…AppImage --appimage-extract-and-run tlj-win-ru`.

Теперь **Play** у TLJ в Steam запускает этот геймпадный билд с твоими данными.

## Схема управления

| Вход | Действие |
|---|---|
| **Левый стик** | Ходьба / бег April (аналог: сильнее отклонил — бежит) |
| **Правый стик** / тач | Курсор |
| **D-pad** | Перескок курсора по кнопкам меню / слотам инвентаря / репликам диалога; в игре — прыжок к выходам |
| **A** / **B** | Клик (взаимодействие) / правый клик (осмотреть) |
| **X** | Пропуск роликов и реплик |
| **Y** | Инвентарь |
| **Create/View** (над крестовиной слева) | Дневник / меню |
| **LB / RB** | Скролл инвентаря / диалогов |
| **LT / RT** | Цикл предметов на курсоре |
| **R3** (нажать правый стик) | Показать все выходы |
| **Start/Options** | Системное меню ScummVM |

Курсор автоматически прячется при ходьбе стиком и мгновенно возвращается при
движении правого стика или касании тача. Крестовиной удобно перекидывать курсор
прямо на иконку двери-выхода — дальше просто **A**.
